# Deployment guide

## 1. Prerequisites

```bash
sudo apt install sway foot swaybg swayidle swaylock iw mate-polkit
# For the native dashboard window (Tauri):
sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev librsvg2-dev libssl-dev
```

Rust (stable) and pnpm are needed to build.

## 2. Audit first (changes nothing)

```bash
scripts/discover.sh                 # reports/hardware-audit-*.md
scripts/discover.sh --baseline 300  # also 5 min discharge baseline; unplug first
```

## 3. Install the session (no boot changes)

```bash
scripts/install.sh           # read the plan
scripts/install.sh --apply
```

This installs `/usr/bin/adg-powerd`, the dashboard, the Sway session, the
polkit action, the root helper, the eco generator and its unit lists in
`/etc/adg-power/`. Each path is recorded in `/var/lib/adg-power/manifest`.

Log out, pick **ADG Power OS** from the gear menu on the login screen. On
login the session starts `adg-powerd`, applies the eco profile (saving the
previous values) and opens the dashboard.

At this stage you are still on the normal boot: Docker, PostgreSQL and the
rest run as usual. Try the session for a few days before step 4.

## 4. Add the boot entry (optional)

```bash
scripts/install.sh --apply --grub
```

This backs up `/boot/grub/grub.cfg` and `/etc/default/grub` to
`/var/backups/adg-power/<timestamp>/`, installs `/etc/grub.d/42_adg_power_os`
and runs `update-grub`. The script checks the new entry exists and restores
the backup if not. The "Ubuntu" and recovery entries are generated by
Ubuntu's own scripts exactly as before.

Booting **ADG Power OS** adds `adgpower.eco=1` to the kernel command line.
The generator sees it and masks the units in
`/etc/adg-power/eco-mask-system.list` and `eco-mask-user.list` under `/run`
for that boot only. Edit those lists to taste; NetworkManager, systemd and
D-Bus units are refused by the generator even if listed.

Need Docker during an eco boot? `sudo systemctl unmask --runtime docker.socket docker.service && sudo systemctl start docker`.

## 5. Privileged settings

The dashboard's "Privileged settings" buttons call
`pkexec /usr/libexec/adg-power/adg-power-helper`, which asks for your
password (cached briefly by polkit) and accepts only:

- `gpu-runtime-pm <pci> auto|on` — writes `power/control` of a display-class PCI device
- `wifi-powersave <iface> on|off` — `iw dev <iface> set power_save`
- `eco-boot-once adg-power-os on` — `grub-reboot adg-power-os`, used by **Restart into Eco mode** in the power menu. Your GRUB menu is hidden (`GRUB_TIMEOUT=0`), so this is the easy way in; the boot after that is normal Ubuntu again.

## 6. Verify (acceptance tests)

| Test | How |
|---|---|
| A normal boot unchanged | Boot "Ubuntu"; `systemctl is-active docker` → active; `docker run --rm hello-world` |
| B eco boot is lean | Boot "ADG Power OS"; `systemctl is-active docker.socket docker containerd postgresql` → inactive; `pgrep containerd-shim` → nothing |
| C Wi-Fi survives UI close | Connect in dashboard, close it, `nmcli -t -f ACTIVE,SSID dev wifi` |
| D Bluetooth audio | Pair headphones in dashboard, Music tile, pick the headset under Audio |
| E/F battery math | `cargo test` (fixtures for BAT1, missing fields, charging, zero draw) |
| G RTX indicator | Dashboard "Suspended" only when `cat /sys/bus/pci/devices/0000:01:00.0/power/runtime_status` says `suspended` |
| H rollback | [rollback.md](rollback.md) |
| I power averages | `scripts/benchmark.sh` per profile → [power-report.md](power-report.md) |
